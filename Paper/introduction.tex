\section{Motivation}
% Single-core performance of HPC kernels depends less on what a loop computes than on the
% form in which it reaches the compiler: source language, code generator (translator, LLM
% agent) and compiler flags. HPCAgent-Bench grades every representation of a kernel
% elementwise against one NumPy reference, which fixes *what* is computed and leaves the
% representation as the only free variable.
% Hook: same kernel, same GCC backend, 6--12x between representations on the
% loop-transformation kernels.
% Agents need domain knowledge they do not have by default -- how to cut a kernel out of
% an application faithfully, which solver optimisations elementwise grading permits --
% and skills are the vehicle for it.
