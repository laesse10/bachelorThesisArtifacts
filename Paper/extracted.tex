\section{Kernel Descriptions}
% One subsection per kernel: mathematics, upstream hot spot, what is graded.
% comet_int4_gemm: 2-bit CCC codes, popcount planes, int32 accumulation, bit-exact.
% quatrex_rgf: selected inversion of a block-tridiagonal system, complex128,
%   O(NB*BS^3) two-pass recurrence per energy point.
% spgemm_hash: boolean (OR,AND) SpGEMM in CSR, five upstream phases (row analysis,
%   binning, hash count, hash fill, sort); cost is de-duplication, not arithmetic.
% warpx_boris_push: relativistic Boris rotation, Full/FirstHalf/SecondHalf branches.
% warpx_esirkepov_deposition: charge-conserving current deposition (scatter-add).
% warpx_field_gather: shape-function interpolation of Yee-grid E/B onto particles.
% triangle_count: degree-ordered DAG, edge-parallel two-phase binary-search intersection.
% nfa_frontier: homogeneous NFA over a byte stream, one component per work item.
